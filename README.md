🔎 Noventra Scan

On-chain token intelligence for TON.

Noventra Scan is a lightweight Telegram Mini App designed to help users quickly inspect TON Jettons before interacting with them.

No complicated dashboards.
No endless searching.
Just enter a Jetton address and scan.

🚀 Features

- 🔎 TON Jetton scanning
- 🪙 Token name & symbol
- 🖼️ Token logo & metadata
- 📊 Total supply
- 👥 Holder count
- 🔢 Token decimals
- 🛠️ Mintable status
- ✅ Verification status
- 🛡️ Basic security signals
- 📈 Noventra Risk Score
- 📋 One-tap contract address copy
- 🌐 TON Explorer access
- 📱 Telegram Mini App optimized UI

---

🧠 Noventra Risk Score

Noventra Scan generates a simple score based on available on-chain signals such as:

- Token verification
- Mintable status
- Holder count
- Available token metadata
- Contract-related information

The score is intended as an informational signal, not a guarantee that a token is safe or legitimate.

Always perform your own research before interacting with any token.

---

⚡ How It Works

1. Open Noventra Scan.
2. Enter a TON Jetton Master Address.
3. Press SCAN.
4. Noventra retrieves available on-chain data.
5. Review the token information and risk signals.
6. Open the token in a TON explorer if you want to investigate further.
